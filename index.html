Projets académiques

Simulateur Radar PPI — Modélisation physique & JavaFX

Projet personnel · 2026 · Java · JavaFX · MVC

Simulateur d'écran radar PPI implémentant l'équation radar fondamentale (SNR = Pt×G²×λ²×σ / (4π)³×R⁴×kTBF), la probabilité de détection via l'approximation d'Albersheim, et le bruit gaussien par méthode Box-Muller. Courbe Pd vs Distance théorique vs mesurée en temps réel. Architecture MVC, faisceau animé 60fps, multi-cibles (avion, drone, missile).

Java JavaFX MVC Albersheim Box-Muller Simulation
